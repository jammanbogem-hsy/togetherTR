# 연수용 모드 설계 명세 (2026-10-04)

배경: 2026-10-09~10 교사 연수. 교사들이 종이·토의로 먼저 결과를 만들고 앱에는 옮겨 적는다. 다른 개발자의 '약식 기록(연수용)' 설계를 우리 앱에 맞게 옮긴다(원문 요약은 사용자 대화 2026-10-04).

## 원칙
- 연수용이 아닌 프로젝트는 지금 동작 그대로. 모든 분기는 `isTrainingActivity(project, code)` 하나를 거친다.
- 협력·개인(solo) 모드 모두 지원. 프로젝트 단위 설정(우리는 워크스페이스가 없음).
- 반드시 지켜야 하는 동작(개입 금지 응답 등)은 프롬프트가 아니라 코드로 보장.
- 되돌림 지점: 태그 `pre-training-mode-2026-10-04` (운영 c6664e88). 작업 브랜치 `feat/training-mode`.

## 데이터
- `Project.trainingMode?: { enabled: boolean; coreFormal: boolean }` — 없으면 일반 모드. coreFormal 기본 true.
- Firestore 규칙 변경 불필요(방장은 프로젝트 전체 필드 수정 가능).

## 핵심 절차(coreFormal=true 일 때 일반 진행)
내부 코드 T-1-1, T-1-2, A-1-2, A-2-1, A-2-2 (표시 T-1, T-2, A-2, A-3, A-4).

## 칸 분류 (src/lib/training/trainingMode.ts 한 파일)
- A 필수: 비면 상태 표시·저장 알림에서 알려 줌.
- B 한 번 묻기: 뒤 활동·보고서가 참고. AI가 한 번만 묻는다(이유 함께 정의).
- C 생략: 묻지 않음. 필요하면 [AI 도움] 버튼.
- 앞 활동 생략 시 한 번 묻는 최소 정보(의존 표).

## 화면
- 새 프로젝트: '연수용 모드' 체크 + 하위 '핵심 절차는 정식으로 진행'(기본 켜짐). 방장 설정에서 변경 가능.
- 약식 활동: 산출물 패널에 설문형 입력 양식(필수/선택 표시). 저장 시 AI 없이 산출물 저장, 'AI 조언 받기' 체크 시에만 짧은 조언. 불러오기 완료 전 저장 금지.
- 채팅 위 연수 막대: 필수 칸 상태, [AI 도움: …], [단계별로 함께 진행], [다음 활동 →].

## AI 동작
- 약식 활동: 짧은 첫 안내, 필수만 확인, B 한 번, 도움은 요청 시만. 역할·말투 규칙보다 우선.
- '개입하지 마세요/조언 필요 없어요/저장만' → 그 활동에서는 AI 호출 없이 '저장했습니다.' (코드). '도와주세요/조언해 주세요/단계별로' → 해제. 시간순 마지막 표현을 따른다.
- 연수용 활동에서는 부재 팀원 확인 카드(#28)·팀원 의견 재요청 비활성.

## 2단계(여유 시)
단계 이동 정해진 문구 기록, 3분 안 지나친 이동 정리, 개입 문구 목록 확장.
