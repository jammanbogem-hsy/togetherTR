# 가입 동의·회원 탈퇴 명세 (2026-10-05)

## 동의 화면 (첫 로그인 + 기존 회원 1회)
- 제목: 개인정보 동의
- 안내: 서비스 이용을 위해 개인정보 수집·이용과 국외 이전 동의가 필요합니다. 처음 로그인하신 분과 기존 회원 모두 한 번 동의해 주셔야 서비스를 이용할 수 있습니다.
- [필수] 개인정보 수집·이용 동의 — 서비스 제공을 위해 이름, 이메일, 프로필 사진 주소(Google 로그인), 서비스 이용 중 작성한 채팅·산출물·업로드 자료를 수집합니다.
- [필수] 개인정보 국외 이전 동의 — AI 응답 생성과 자료 분석을 위해 채팅·산출물·업로드 자료 내용이 미국 OpenAI와 미국 Anthropic으로, 성취기준 판정 문장이 TypeSafe(Jev) 판정 서비스로 전송됩니다. 계정 정보와 설계 데이터는 대한민국(서울) Google Firebase에 저장되며, 전송은 암호화된 연결로 이루어집니다.
- 거부 권리: 동의를 거부할 수 있으나, 거부하면 AI 공동 설계가 중심 기능인 이 서비스를 이용할 수 없습니다.
- 보유 기간: 회원 탈퇴 시까지. 탈퇴는 설정의 '회원 탈퇴'에서 직접 할 수 있습니다. 탈퇴 후 남은 업로드 자료는 순차 삭제됩니다.
- 버튼: 동의하고 계속하기 / 동의하지 않고 나가기(로그아웃)
- 자세한 내용 보기: 수집 항목·이용 목적·보유 기간 표, 국외 이전 표(받는 곳·나라·항목·목적·방법·보유 기간).
- 기록: users/{uid}.privacyConsent = { version, agreedAt, items: ['collect','overseas'] }. 문구 바꾸면 version 올려 재동의.

## 회원 탈퇴 (기본안)
- 위치: 대시보드 계정 메뉴/설정 '회원 탈퇴'. 확인 창에서 처리 내용 안내 + '탈퇴' 입력 후 버튼 활성.
- 처리(서버 API, firebase-admin, ID 토큰 검증):
  1) 혼자만 멤버인 프로젝트(개인 설계 포함): 삭제(하위 컬렉션 포함).
  2) 팀 프로젝트 방장: 남은 팀원 중 가장 먼저 참여한 사람에게 방장 넘김 후 본인 멤버 제거.
  3) 팀 프로젝트 팀원: 멤버에서 제거.
  4) 팀 프로젝트에 남긴 대화·산출물은 팀의 공동 기록으로 남김(동의서에 명시).
  5) users/{uid} 문서 삭제, Firebase Auth 계정 삭제, 로그아웃.
- 동의서 보유 기간 문구에 4)를 함께 적는다: '팀 프로젝트에 남긴 대화와 산출물은 팀의 공동 기록으로 남습니다.'

## Storage 정리 실패 보완 (2026-10-06, 미배포)
- 삭제 전에 관리자 전용 storageCleanupQueue에 prefix·uid 해시를 기록한다. 기록 실패 시 삭제 중단, 자료 삭제 실패 시 기록을 유지하고 관리자 API로 재시도한다.
- 남은 목록이 있으면 탈퇴 완료 화면에 “탈퇴가 완료되었습니다. 일부 업로드 자료는 정리 중입니다”를 표시한다. 동의 버전 2026-10-06.
- 관리자 권한·재시도 절차와 검사 범위는 [운영 안내](storage-cleanup-operations.md)를 따른다. 운영 배포와 실제 탈퇴 시험은 별도 승인 전 보류한다.
