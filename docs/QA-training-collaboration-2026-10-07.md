# 연수 협업 사용성 보완 검증

## 변경 범위

- 채팅 표의 내용 열 최소 폭과 짧은 평가 열 너비를 조정하고, 표 클릭/‘표 크게 보기’로 native dialog를 연다. 모바일에서는 표 내부만 스크롤한다. 체크박스·링크 조작과 글 선택은 확대 동작을 일으키지 않는다.
- 체크리스트를 메시지/항목/uid별로 저장한다. 이전 공동 기록은 별도 표시하며 개인 체크로 복제하지 않는다. 실패 시 본인의 해당 변경만 되돌리고 다른 사람/더 최신 변경은 보존한다.
- AI 응답은 시작 위치에서 읽고 긴 응답을 자동 추격하지 않는다. 수동 스크롤을 보존하고 새 응답 안내로 시작 위치에 복귀한다. 보고서 생성·새 버전은 맨 위에서 시작한다.
- 검토 요청의 추가 입력 버튼은 작성 중인 입력을 유지하면서 확인할 내용만 덧붙인다. 자동 전송하거나 산출물을 저장하지 않는다.
- 연수용 이전 산출물 목록을 일반 화면과 같은 렌더러로 표시한다. 필수 항목 완료 판정은 연수 양식과 같은 정규화 경로를 사용하여 글·표·구조화 저장을 동일하게 취급한다.
- 약식 연수 활동의 명시적인 ‘다음’ 요청은 AI 호출 전에 처리한다. 기록 담당 권한, 미저장 제안 보호, 단계 경계의 이동 창을 유지한다. 일반/핵심 정식 활동은 기존 이동 확인 경로를 따른다.
- 연수 안내는 완성할 결과·할 행동을 먼저 알리고 충분한 정보가 있으면 수정 가능한 초안을 제안한다. 프롬프트 검증이며 실제 모델 응답 품질을 보장한 실험은 아니다.
- Ds-5 첫 안내: ‘어려움이 예상되는 활동에 제공할 수 있는 지원을 적어요.’
- 교육과정 자동 채우기는 최종 선정 주제, 현재 교사의 최근 발언, 앞 활동 산출물 맥락을 전달한다. 낮은 관련성/기존 선택과의 불일치는 명시적으로 확인한다. 시트 수동 저장은 실제 응답 후 성공 안내를 표시하고 실패 시 입력을 보존한다.
- 문제상황 워크숍의 확정 선택은 저장을 실행한다. 성공 응답 전에는 저장 완료를 표시하지 않고, 저장 실패는 안내와 재시도를 제공한다.
- 생성 파일인 영역 매핑을 배포 빌드 전 기존 원본/생성기로 재현한다. 현재 큰 통합 레코드에서 12개 매핑을 생성하며 작은 영역별 레코드는 기존 원본 경로를 사용한다.
