## 변경 내용

- 분석시트의 공통 상단 바·세그먼트 버튼·도움말·버튼 및 색상 토큰을 재사용합니다. 주제 검색과 검색 방식, 관계 필터를 별도 도구 영역에 배치합니다.
- 성취기준 목록에 본문 미리보기와 초등 학년군을 표시하고 중심 성취기준을 같은 파란색 선택 스타일로 강조합니다.
- 수업 예시 생성·분석시트 저장·돌아가기를 하단 고정 영역에 배치합니다. 저장 말풍선이 생성 버튼을 가리던 문제를 없애고 도움말도 펼침 영역으로 제공합니다.
- 노드의 과목 아이콘과 연결 유형 색상은 유지합니다. 창 크기 변경 및 패널 접기 후 그래프를 화면에 맞추며, 작은 화면의 목록은 접힌 상태로 시작합니다.
- 저장 실패를 저장 완료로 표시하지 않도록 오류를 전달하고 재시도 안내를 표시합니다. 분석 중 저장을 비활성화하고 팀장 전용 저장 권한을 유지합니다.
- 연결 구조 상세 창을 같은 UI로 맞추고 키보드 초점, Escape 닫기, 초점 복귀를 지원합니다.
