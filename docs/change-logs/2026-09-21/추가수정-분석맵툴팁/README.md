# 분석맵 중복 설명 및 툴팁 위치 수정 (2026-09-22)

대상: https://jammanbo-curriculum-map.web.app

문제: 관계 근거를 캔버스 연결선 중간과 노드 툴팁에 동시에 표시해 긴 문장이
툴팁 뒤로 튀어나왔습니다. 툴팁 높이를 160px로 가정해 긴 설명이 화면 아래로
잘리기도 했습니다.

변경:
- 관계의 긴 설명은 노드 툴팁과 분석 패널에서 표시하며 캔버스에는 중복하지 않음.
- 실제 툴팁 크기를 측정해 오른쪽·아래쪽 경계에서 왼쪽·위쪽으로 이동.
- 폰트·문장 길이·창 크기가 바뀌면 위치를 다시 계산.
- 확대·축소·화면 이동을 시작할 때 이전 툴팁을 지워 오래된 위치에 남지 않도록 함.

공유 컴포넌트를 수정했으며 이번 운영 배포 대상은 별도 공개 사이트입니다.
