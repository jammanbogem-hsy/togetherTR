# 협력적 수업설계 멀티에이전트 v2 검증

## 범위

사용자 승인 후 기존 2~5명 교사 AI 데모를 개선했다. 실제 인간 교사의 실시간 참여 기능이나 공개 배포는 이번 범위가 아니다. 기존 일반 프로젝트와 이전 검증 프로젝트 `DyEIRmbkwWqE5N1emgsN`은 보존했다.

## 구현

- 19개 활동의 공유 교육 계약: 활동별 2개 작업 단계, T-1은 3개. 총괄 AI가 먼저 실제 과제를 제시하고 각 교사가 수행한다.
- 각 작업의 독립 발언 → 실제 동료 발언 인용·응답 → 공동 초안 → 교사별 독립 검토. 전원 승인 전에는 확정하지 않는다.
- 수정 요청 시 최대 2회 공동 초안 수정·재검토. 미합의는 초안과 이견을 보존하고 중단하며, 무의미한 재시도 대신 새 설정을 안내한다.
- 교사 누락, 표의 필수 열·행, 원칙 형식, 실제 활동지·CSV·루브릭, 모의 관찰 장면, E 성찰의 존재하는 장면 ID 등을 검증한다. 구조 검증이 교육적 품질 전체를 보증하지는 않는다.
- 모든 이전 활동의 산출물과 실제 발언 발췌를 누적 전달한다. DI 자료와 모의 관찰 본문은 잘리지 않도록 우선 보존한다.
- Firestore 트랜잭션 실행권과 대화·응답의 원자적 저장으로 중복 탭, 늦은 응답, 중단 후 발언 삭제를 방지한다. 실행은 여전히 브라우저에 의존한다.
- 데모 프로젝트는 관찰 전용이다. 일반 채팅 AI/수동 단계 변경/인간 승인 표현을 배제하고, 대화·중간 초안·교사 검토·최종 산출물·보고서를 Markdown 튜토리얼로 내려받는다.
- 일반 T-2 표의 2열·새 4열 파싱 호환성을 유지하고 멈춤 조건을 보존한다.
- 실제 중단을 분석한 뒤 교사 검토를 고정 활동 기준에 연결한 필수 수정과 후속 제안으로 분리했다. 필수 수정은 기준 ID·초안 섹션·실제 원문 인용·문제·수정안을 요구한다. 존재하지 않는 기준/인용과 결정 불일치를 거절하지만, 지적의 교육적 타당성까지 결정적으로 판정하지는 못한다.
- T-2 원칙 조정 안내에 실제 번호 있는 원칙 3~5개가 없으면 다음 교사 작업으로 넘어가지 않는다. 내부 필드명 노출 검증을 보강했다. 이미 저장된 문제 발언은 소급 변경하지 않았다.
- GPT-5 계열 교사 검토 턴은 추론 수준 medium, 출력 예산 8192 토큰으로 높였다. 다른 턴은 기존 설정을 유지한다. 검토 지연과 비용은 증가할 수 있다.
- 구조화된 필수 수정·후속 제안을 관찰 화면과 Markdown에 모두 보존한다. 미확정 초안의 승인 집계 전 0명 값을 실제 동의자 수로 잘못 보여주지 않는다.

## 실제 실행

- 새 프로젝트: `8WQZbABthw03Cr5tTPB2`
- 설정: 초등 5~6학년, 4차시, 측우기·동일 조건 측정·합성 강우 자료·학교 텃밭 물 주기 계획.
- 교사 AI: 김하늘(과학·수학), 이도윤(사회·국어), 박서연(특수·통합교육). 총괄 AI 별도.
- 모델: 현재 서버 설정의 `gpt-5-mini`.
- 기본 289턴. 검토에 따른 수정 회차는 추가된다.
- 첫 실행에서 내부 출력 필드명을 자연어에 섞는 응답과 불필요한 빈 인용 배열 항목을 발견했다. 일시정지 후 회귀 테스트·출력 스키마를 보강했다. 이미 저장된 최초 발화는 감사 이력으로 남기고 같은 프로젝트에서 재개한다.
- 실제 복구 중 정상 GFM 짧은 구분선을 검증기가 거절하는 문제와 화면 이벤트 중복 key 문제를 발견하여 회귀 테스트 후 수정했다. 개발 새로고침으로 남은 실행권은 임의 해제하지 않고 만료 후 재개한다.
- 최종 프로젝트 실행 결과: **42턴 저장 후 T-2에서 미합의 중단**. T-1은 교사 AI 3명의 승인으로 확정되었고 T-2는 v3 검토 초안이다. T-3부터 E-2까지 17개 활동은 이 프로젝트에서 실행하지 않았다. 전체 19개 활동 완주 검증은 미완료다.
- 중단 원인: 일부 교사 AI가 이미 충족된 원칙 표에 파일명·확인 서식·검증 인원 등 후속 단계의 세부 절차를 계속 추가 요구했다. 2회 수정 후에도 김하늘·이도윤은 수정 요청, 박서연은 승인했다. 엔진은 전원 승인으로 꾸미지 않고 초안·발언·검토 이력을 보존했다. 단순 재시도는 저장된 결정을 재생하므로 이 미합의를 해결하지 않는다.
- T-1에서는 실제 개인 키워드 → 3개 비전 후보 비교 → 서로 다른 선택과 문장 수정 → 공동 비전 → 교사별 승인 흐름을 확인했다. T-2에서는 상호 인용과 공동 초안 수정이 일어났지만, 총괄의 중간 원칙 표 미제시와 과도한 행정 요구가 협의를 흐렸다. 대화가 존재한다는 사실과 교육적으로 적절한 협력이 완성됐다는 주장은 구분한다.

## 중단 후 집중 모델 검증

`node --env-file=.env.local scripts/check-demo-review-live.mjs --live`는 명시적으로 실행하는 유료 진단이다. 실제 저장 산출물의 복제본이 아닌 **별도로 구성한 T-2 회귀 사례**를 사용하며 Firestore와 프로젝트 승인 상태를 변경하지 않는다.

- 동일한 구성 사례: 형식·비전 근거·멈춤 조건을 충족하는 원칙 4개, 이전 교사 검토가 행정 서식 추가를 요구했고 총괄이 이를 후속 단계로 분리한 상황.
- `gpt-5-mini` minimal: 3명 모두 수정 요청. 충족한 조건을 결함으로 다시 지적하는 자기모순과 없는 수치 기준 요구를 확인했다. 구조화 검토만 추가해서는 충분하지 않았다.
- 같은 모델 medium: 3명 모두 필수 수정 없이 승인, 추가 의견을 후속 제안으로 분리했다. 이에 검토 턴의 추론 설정을 보완했다.
- 단일 구성 사례의 결과이며 다른 입력이나 전체 실행의 안정성을 입증하지 않는다. 후속 제안에도 근거 없는 임의 수치와 부정확한 문구 지적이 남아 있어 자동 채택하면 안 된다. 마지막 보완 이후 새 프로젝트의 전체 재실행은 하지 않았다.

## 해석 범위

교사 AI의 합의는 인간 교사의 승인이 아니다. DI/E 기록은 합성·시뮬레이션이며 실제 학생의 학습 효과를 증명하지 않는다. E의 변경 전·후 문안은 개선 산출물로 저장되며 기존 DI 원문을 자동 덮어쓰지는 않는다. 교육과정 원문·지역 자료·학교 여건은 실제 적용 전에 교사가 확인해야 한다. 외부 공개 전 API 인증/비용 제어는 별도 점검이 필요하다.

## 남은 검증

1. 마지막 보완을 포함한 새 프로젝트에서 19개 활동 전체 완주와 단계별 교육적 품질을 확인해야 한다. 현재 결과는 공유 가능한 완성 튜토리얼이 아니라 실패 원인까지 남긴 검증 프로젝트다.
2. 실제 DI 활동지·CSV·평가표의 사용 가능성과 E의 수정 문안을 실제 모델 출력으로 확인해야 한다. 해당 구간은 현재 자동 테스트와 계약 검증만 통과했다.
3. 후속 제안의 타당성, 장시간 브라우저 실행 안정성, 공개 공유 권한·인증·비용 제어는 추가 확인이 필요하다. 이번 변경에서 공개 배포나 Git 커밋·푸시는 하지 않았다.
