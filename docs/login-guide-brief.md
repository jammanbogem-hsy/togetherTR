# /login 안내형 로그인 페이지 — 디자인·구현 브리프

## 목표
`/login`을 단순 로그인 카드에서 **"서비스 안내 + 로그인" 통합 랜딩 페이지**로 재구성.
레퍼런스: https://curriculum-weaver.vercel.app/guide (같은 T-CID 모형 기반의 자매 플랫폼 가이드 페이지)

## 절대 제약 (위반 금지)
1. **기존 기능 무변경**: 로그인 로직(`signInWithGoogle`, `completeProfile`, 2단계 흐름: Google 로그인 → 신규 사용자 프로필 완성 → /dashboard 이동)을 그대로 보존. `src/lib/auth.ts` 및 다른 페이지·컴포넌트·전역 파일 수정 금지.
2. **수정 허용 범위**: `src/app/(auth)/login/page.tsx` + 같은 디렉토리에 새 파일 추가(`src/app/(auth)/login/` 하위 컴포넌트)만. `globals.css`는 기존 규칙 수정 금지 — 새 클래스 추가가 꼭 필요하면 파일 끝에 append만 허용(기존 어느 줄도 변경 불가).
3. `layout.tsx` 수정 금지 — Google Fonts 추가는 `next/font/google`을 login page 모듈에서 직접 import (모듈 스코프 상수).
4. 라우트 추가·변경 금지 (`/login` 유지, `/guide` 신설 아님).

## 레퍼런스 페이지 구조 (실측 — 스크린샷·전문 확보됨)
1. **고정 상단 네비**: 좌측 로고+서비스명 / 우측 보조 링크 + primary 버튼(시작하기)
2. **Hero**: 중앙 정렬 — 배지 칩("협력적 수업 설계를 AI 에이전트와 함께!") → 초대형 2줄 헤드라인 → 3줄 서브카피(감성적 — "성취기준이 별처럼 펼쳐진 교육과정의 우주") → CTA 버튼 2개
3. **QUICK START — "4단계로 시작하세요"**: 번호 원형 뱃지 + 제목 + 설명 + 브라우저 목업 카드(신호등 점 3개 헤더), 2열 지그재그
4. **WORKFLOW — 5개 과정·18개 세부활동**: 단계별 파스텔 색상 대형 카드(T 보라 / A 파랑 / Ds 초록 / DI 노랑 / E 빨강) 안에 활동 칩(점 + "T-1 공동 비전 설정" 형식), 하단에 T→A→Ds→DI→E 원형 플로우
5. **AI CO-DESIGNER**: AI 4역할 2×2 카드(📌안내·✍생성·🔍점검·📝기록) + 실제 채팅 목업(사용자 말풍선/AI 응답/수락·편집·거부 버튼)
6. **AI 역할 선택**: 기록자/조언자/사회자(기본)/공동설계자 4카드
7. **DESIGN BOARDS**: 체크리스트 4개 + 보드 목업
8. **DESIGN PRINCIPLES — 5가지 협력 원리**: 태그 5개(활성화·외현화·조정·상호의존·인지분산) + 원리 패널 목업
9. **REAL-TIME COLLABORATION**: 체크리스트 + 실시간 협업 목업
10. **CURRICULUM GRAPH**: 교과 연결 탐색 설명 + 그래프 목업
11. **TRY DEMO / FAQ 아코디언 / 최종 CTA / 푸터**
- 섹션 공통 패턴: 영문 스몰캡 오버라인(예: "WORKFLOW") + 대형 한글 제목 + 설명 문단 + (체크리스트) | 목업 카드. 좌우 교차 배치. 스크롤 페이드인.

## 우리 서비스(T-CID 협력 수업설계 · togethertr)에 맞출 실제 기능 목록 (카피는 이 사실에 근거)
- Google 로그인 → 프로필(이름·학교급·학교명·학년) → 대시보드
- **초대 코드**로 팀원 참여, 호스트(방장) 진행 제어, Firestore 실시간 동기화(채팅·산출물·활동 상태 공유)
- **T-CID 5단계 흐름** (농사 메타포 — 가이드 문서 공식):
  - T 팀준비 "협력의 밭을 일구는 시간" (T-1~T-5)
  - A 분석 "우리 땅을 살피고 씨앗을 고르는 시간" (A-1~A-5, A-5 학습자·맥락 분석은 앱 고유)
  - Ds 설계 "배움의 텃밭을 함께 그려가는 시간" (Ds-1~Ds-5, 평가 먼저 Backward Design)
  - DI 개발·실행 "우리의 협력이 꽃피우는 시간" (DI-1~DI-2)
  - E 평가 "우리의 열매를 거두는 시간" (E-1~E-2) → E에서 다시 T로 순환(다음 주기)
- **AI 퍼실리테이터**: 활동별 절차 안내, 팀 토의 제안, 산출물 초안(A안/B안 확정), 협력 UP 5원리 기반 촉진, 개인별 실명 언급 피드백
- **산출물 패널**: 활동별 산출물 실시간 반영·확정, 워크스페이스 모달(비전·규칙·일정·평가 등 12종 공동 편집 + AI 제안)
- **지식 그래프**: 성취기준 탐색·고정(A-3 분석 연동)
- **보고서**: 단계 분석 보고서, 누적 종합 보고서(HWPX/PDF 내보내기), 공유 링크
- **협력 UP 5원리**: #활성화 #외현화 #조정 #상호의존 #인지분산
- 학교급: 초·중·고 지원

## 기존 디자인 시스템 (반드시 재사용)
- 팔레트: primary #1A73E8, primary-container #E8F0FE, surface #FFF, background #F8F9FA, on-surface #202124, on-surface-variant #5F6368, outline #DADCE0 (Google Material 계열). 로그인 그라데이션: `linear-gradient(135deg,#EAF2FF 0%,#F8F9FA 50%,#F3E5F5 100%)`
- 단계색(사이드바 기준): T 보라·A 파랑·Ds 초록·DI 노랑·E 빨강 계열 파스텔 (레퍼런스와 동일 관습)
- 기존 클래스: `project-card`(코너 그라데이션 호버 카드, --cc/--cx/--cy 변수), `morph-btn`, `morph-shape`/`stage-bounce` 키프레임(로고 블롭 애니메이션), shadow-1~3 토큰
- 폰트: Noto Sans KR(--font-noto) 기본. **Google Fonts에서 헤드라인용 디스플레이 폰트 1종 추가 선정** (next/font/google — 한글 지원 필수. 후보: Gowun Batang(명조 감성), IBM Plex Sans KR, Nanum Myeongjo 등 — 디자인 에이전트가 근거와 함께 확정)
- 아이콘: lucide-react (이미 사용 중) + 이모지 병용 가능
- 로그인 카드 UI(기존): BookOpen 로고 블롭, Google 버튼(공식 4색 SVG), 프로필 폼 — **시각·로직 그대로 재사용**

## 페이지 구성 방향 (디자인 에이전트가 상세화)
- 상단 고정 네비(로고 + "로그인" 스크롤 버튼) + Hero에서 **로그인 카드를 우측(데스크톱) 또는 헤더 직하(모바일)에 항시 노출** — "설명을 읽지 않고도 즉시 로그인 가능"이 UX 원칙
- 이후 안내 섹션: 4단계 시작(로그인→팀 구성/초대→프로젝트 생성→AI와 설계) → 5과정 워크플로우(농사 메타포+표시 번호 활동 칩) → AI 퍼실리테이터 소개 → 협력 UP 5원리 → 실시간 협업·산출물·보고서 → FAQ(선택) → 최종 CTA(로그인으로 스크롤)
- 목업은 실제 스크린샷이 아닌 **경량 CSS 목업**(레퍼런스 방식)으로 구현
- 반응형 필수(모바일 1열), 스크롤 리빌은 CSS 또는 IntersectionObserver 경량 구현
- 접근성: 시맨틱 헤딩 위계, 대비, 포커스 스타일

## 산출물 경로
