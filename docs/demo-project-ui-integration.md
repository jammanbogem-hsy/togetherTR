# 데모의 기존 프로젝트 UI 통합

- `/projects/[id]`의 데모 전용 전체 화면 분기를 제거했다. 일반 프로젝트와 같은 활동 사이드바, 단계 바, 중앙 채팅 영역, 우측 산출물 영역, 패널 접기, 팀원 목록, 보고서·구조도 진입을 사용한다.
- 데모의 단계 선택과 활동 선택은 `viewingActivity`만 바꾸며 엔진의 저장된 실행 위치는 바꾸지 않는다. 기존 일반 프로젝트의 방장 전환 동작은 유지한다.
- 우측 상단 `AI 튜토리얼` 메뉴에 실행 상태·제어 링크·다운로드·페르소나·보고서를 넣었다. 중앙 상단을 별도로 차지하던 도구막대는 제거했다.
- 실제 프로젝트와 데모가 `ChatPanelHeader`, `ChatFontScaleControl`, `MessageBubble`을 공통으로 사용한다. 데모 대화 구독 컨트롤러만 분리하고, 일반 전송·환영 메시지 생성 컨트롤러는 마운트하지 않는다. 입력 영역은 데모에서 비활성화한다.
- 산출물은 실제 프로젝트의 `InteractiveArtifactPanel`을 공통으로 사용해 상태 배지·버전 이력·필수항목 카드·섹션 카드·확대 보기를 표시한다. 데모에서는 확정·삭제·수정 요청·버전 되돌리기·채팅 주입을 제한하고 AI 교사 합의임을 표시한다.
- 좁은 산출물 영역의 표에는 가로 스크롤을 제공하고, `3~5개`, `1~2문장` 같은 범위 표기를 취소선으로 해석하지 않도록 보완했다.

## 검증

- 타입 검사, 관련 동작·렌더링 테스트 25개 통과. 범위 표기 회귀 검사 통과.
- 프로덕션 빌드 및 런타임 자료 검증 통과.
- 실제 프로젝트 `Oo6ggDA8pj8dBuAAxvse`에서 3열 레이아웃을 시각 확인했다. E에서 T 단계 클릭 시 T 활동 목록과 T-1 대화·산출물이 표시되고, T-2 클릭 시 양쪽 패널이 함께 전환되는 것을 확인했다. 실행 위치로 복귀하면 E-2가 표시돼 과거 활동 탐색이 실행 위치를 변경하지 않았음을 확인했다.
- 같은 프로젝트의 현재 저장 상태는 `실행 완료`로 표시된다. 이전 검증 기록의 98% 상태 보류는 현재 관찰 결과로 해소됐다.
- 내부 UI 후속 검증: 데모와 실제 `BsCjQkXsNg1SZU4Swm6h` 프로젝트를 모두 T-2로 열어 화면을 비교했다. 공통 헤더·말풍선·산출물 카드를 시각 확인했고, 데모의 글자 크기를 100→110→100%로 조절했다. 데모 입력창은 disabled이며 산출물 변경 버튼이 노출되지 않는 것을 확인했다. 일반 프로젝트는 기존 입력·노트·공동편집·확정 관리 UI를 유지한다.
