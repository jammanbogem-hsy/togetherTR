# 저학년 미개설 교과 → 통합교과 연결 수정

수정 전 커밋: `8582c31bf125ce22fccce57d864546f03c86fced`
수정 코드 커밋: `05cd8041cb10b8b2b509fbdc0751738146f09329`

## 변경 내용

- 기존에는 명시적으로 만든 연결 줄만 다른 교과를 검색했습니다. 일반 학년군 줄도 1-2학년 미술·음악·사회처럼 해당 교과가 없으면 **유사 성취기준** 검색으로 연결합니다. 데이터 로딩 전에도 교과 개설 정보를 사용하며, 같은 교과 검색이 404로 끝나도 연결 검색으로 이어집니다.
- 검색 결과 상한 때문에 통합교과가 목록에서 모두 탈락하지 않도록 저학년 대체 교과 후보를 확보하고, 통합교과 후보를 먼저 보여 줍니다. 관련도 점수는 바꾸지 않습니다.
- 후보를 선택하면 실제 교과·학년군·핵심아이디어·성취기준을 함께 저장하고 원래 미술 등의 핵심아이디어는 linkedCoreIdea로 보존합니다. 기존 행 ID·학년군 중심 여부·교사 설명도 유지합니다.
- 통합교과 내용 요소는 바른 생활/슬기로운 생활/즐거운 생활을 구분합니다. 분석시트용 내용체계 API는 과목별 원문을 분리하고, 선택한 2바/2슬/2즐 성취기준의 과목에서 지식·기능·태도를 가져옵니다.
- 검색 중 교육과정 입력이 바뀌면 이전 후보를 적용하지 않습니다. 빈 수업내용 설명만 기존 설명 작성 절차로 채웁니다.

## 검증

- 관련 테스트 68개 통과. 실제 교육과정 DB 기반 API 테스트 포함(외부 모델 호출만 테스트 응답으로 대체).
- TypeScript 및 변경 파일 ESLint 통과.
- 로컬 실제 API에서 미술 핵심아이디어와 1-2학년군을 보내 `[2슬04-02] 상상한 것을 다양한 매체와 재료로 구현한다.`, `[2즐02-04] 다양한 세상을 상상하고 표현한다.` 등을 찾았습니다.
- 실제 시트 화면에서 일반 미술 줄 → 유사 검색 → 통합교과 성취기준·내용 요소·빈 설명 적용, 고학년 행 유지, 원본 핵심아이디어 연결·학년군 중심 유지, 교사 설명 보존, 검색 중 편집된 행 보호 확인.
- 화면 검증에서는 저장을 메모리로, 설명 생성을 테스트 응답으로 대체했습니다. 반복 선택/동시 편집 시나리오는 앞서 확인한 공식 후보를 재사용했습니다. 임시 검증 페이지는 배포 소스에서 제거합니다.
