## 변경 내용

- 교육과정 분석시트의 공통 상단 바·하단 바·라벨·버튼과 색상 토큰을 재사용합니다. 모달만 운영체제의 다크 모드에 따라 색상이 달라지던 별도 팔레트를 제거합니다.
- 넓은 화면에서는 교육과정 분석시트 내용과 연결 성취기준을 두 열로, 작은 화면에서는 한 열로 표시합니다. 본문만 스크롤하고 제목과 돌아가기 버튼은 고정합니다.
- 과목 아이콘·성취기준 본문을 상단에 표시하고 핵심아이디어·지식·기능·추천 수업 예시·수업내용 설명을 구분합니다.
- 연결 성취기준에 학년군과 그래프와 같은 관계 색상을 표시합니다. 여섯 개를 넘는 연결도 모두 표시하며, 미분석 관계는 관계 추정으로 구분합니다.
- 수업 아이디어·제안·근거 및 다시 분석 기능을 유지합니다. 분석 중 버튼은 잠그고 팀원에게는 권한에 맞는 안내를 표시합니다.
- Escape 닫기, Tab/Shift+Tab 모달 내부 이동, 닫은 뒤 원래 버튼으로 초점 복귀를 유지합니다.
