# 교육과정 내용 체계 JSON

이 폴더는 과목별 교육과정 PDF에서 `가. 내용 체계` 표만 분리한 JSON을 둔다.

## 파일 규칙

- 파일명: `{과목명}내용체계.json`
- 스키마: `메타.스키마` 값은 `curriculum-content-system.v1`
- 최상위 구조: `메타`, `내용체계`

## 내용체계 항목

공통 교육과정처럼 학년군이 있는 표는 `학년군별`을 사용한다.

```json
{
  "교육과정": "공통 교육과정",
  "과목": "도덕",
  "영역": "자신과의 관계",
  "핵심아이디어": [],
  "학년군별": {
    "3-4학년군": {
      "지식⋅이해": [],
      "과정⋅기능": [],
      "가치⋅태도": []
    }
  }
}
```

선택 과목처럼 단일 내용 요소 표는 `내용요소`를 사용한다. `지식⋅이해`는 질문과 하위 요소를 분리한다.

```json
{
  "교육과정": "선택 중심 교육과정",
  "과목군": "일반 선택 과목",
  "과목": "현대사회와 윤리",
  "영역": "현대 생활과 윤리",
  "핵심아이디어": [],
  "내용요소": {
    "지식⋅이해": [
      {
        "질문": "",
        "요소": []
      }
    ],
    "과정⋅기능": [],
    "가치⋅태도": []
  }
}
```

PDF 표 셀 인식이 완전하지 않은 과목은 `내용요소`를 우선 활용하고, 검산을 위해 다음 보조 필드를 함께 둘 수 있다.

- `표원문`: PDF에서 추출한 내용 체계 범위의 원문 텍스트
- `표`: PDF 표 추출기가 반환한 쪽별 표 행 데이터

창의적 체험활동처럼 일반 교과의 `핵심 아이디어`, `지식⋅이해`, `과정⋅기능`, `가치⋅태도` 표가 없는 교육과정은 원문에 제시된 `영역`, `활동`, `활동 목표`, `예시 활동`을 보존하고, 활용 편의를 위해 세 범주에 대응시킨다. 이 경우 원 표 구조는 `활동내용` 필드에 함께 둔다.

## 검증

전체 과목 파일을 검증한다.

```bash
npm run validate:curriculum-content-systems
```

특정 파일만 검증한다.

```bash
node scripts/validate-curriculum-content-systems.mjs data/curriculum-content-systems/도덕내용체계.json
```

다른 과목을 추가할 때도 같은 폴더에 `{과목명}내용체계.json`을 만들고 위 검증을 통과시키면 된다.

## 제품 적용 방식

내용체계 컨텍스트 주입은 기존 성취기준 검색, 지식 그래프, A-2-1 자동 저장 흐름을 바꾸지 않는 선택형 보조 레이어다. 기본값에서는 비활성화되어 기존 제품 동작이 유지된다.

서버 환경변수로 활성화한다.

```bash
CURRICULUM_CONTENT_SYSTEM_CONTEXT=enabled
```

활성화 시 A단계와 Ds단계의 교육과정 컨텍스트 끝에 `내용체계 기반 보조 근거` 블록이 추가된다. 이 블록은 성취기준 코드나 지식 그래프 선택 결과를 대체하지 않으며, 핵심아이디어와 `지식⋅이해`, `과정⋅기능`, `가치⋅태도`를 채우거나 검산하는 데만 사용한다.
